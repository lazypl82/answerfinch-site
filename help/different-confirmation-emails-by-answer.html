Send different Google Forms confirmation emails based on an answer

If your Google Forms™ respondents need different instructions, write a separate confirmation for each answer. Send each message to the person who filled in the form. On Free you can run one rule at a time across your Google account. You need Pro to run both at once.

By Lazy Labs. November 19, 2026. Steps checked against Answerfinch v8.

Give each person one way to answer

Make “How will you attend?” a required Multiple choice question. Use Online and In person as the options. Each respondent selects one option, so the two rules below can't both match the same answer.

If you collect email addresses in Google Forms, you can use the collected address. Otherwise, add a required Short answer question for the email address and set email validation. If Answerfinch can't check whether collection is on, choose the question that holds the respondent's address.

Write a rule for each answer

If you see Run this rule on Free instead when you open a new rule, choose it to open the editor. You can choose which rule runs after you save.

  1. Open Answerfinch from the add-on menu. If prompted, choose Start in this form. Choose Create a rule, or New rule if you already saved a rule here.
  2. Enter “Online instructions” in Rule name. Under When, pick “How will you attend?”, choose is, and select Online. Under Send to, pick The person who filled in the form. Choose Email collected by Google Forms or your email question.
  3. Write a subject such as “How to join the online session.” Include your meeting link and the start time. Choose Save, then Save rule.
  4. Choose New rule and enter “In-person instructions” in Rule name. Pick the same question. Choose is and select In person. Choose the same respondent address source. Write a subject and a message with the location and check-in instructions. Choose Save, then Save rule.

Write what the person needs to do next. If you need a detail from their answer, such as their name, put your cursor in the subject or message and choose Insert answer.

Test each message with your own address

  1. In a test copy, submit an Online response and an In person response. Use your own address for both.
  2. Open each rule and check the subject, address and message in Preview with the corresponding response. If you see Select a response, choose your sample. If you see Latest response (no recent match), check that you picked the right response and rule.
  3. Turn on alerts. On Free, if you need to switch rules, choose Keep this rule on Free for the rule you want to test and confirm the switch. Then choose Send me a test. Check the sample and choose Send test to myself.

If you test your first rule before you add the second, you can use Preview and test when it appears. Check the sample and choose Turn on alerts and send test. Both test paths send the email to you.

On Free, when you choose the other rule, you pause the one you were using. To check what happens when both rules run, use Pro and submit fresh sample responses after both are active. Check the messages in your inbox as well as Send log.

When to use a different setup

If respondents just need a copy of their answers, use Google Forms response receipts. If you leave receipts on as well as these rules, respondents can get both emails. If the message is only for the screen they see after submitting, use the confirmation message setting in Google Forms.

If all respondents should get the same instructions with a few details filled in, write one personalized confirmation. The rules here send instructions. You still need to handle seat availability or approve attendance yourself.
