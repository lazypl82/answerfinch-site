Email different people based on Google Forms checkbox answers

When respondents can select several answers, use a separate rule for each address you want to email. If several options should go to one address, group them in one rule. On Free you can run one rule at a time across your Google account. To run several routes at once, use Pro.

By Lazy Labs. November 19, 2026. Steps checked against Answerfinch v8.

Decide who needs to know

In Google Forms™, make a Checkboxes question called “What do you need?” Add Room setup, Microphone and Projector. Leave the question optional if people can submit without asking for equipment or setup.

  • Send Room setup requests to the facilities team.
  • Send Microphone and Projector requests to the same AV address.

You don't need to collect respondents' email addresses for these rules. Use addresses you control while testing.

Set up the routes

If you see Run this rule on Free instead when you open a new rule, choose it to open the editor. You can choose which rule runs after you save.

  1. Open Answerfinch from the add-on menu in the form. If prompted, choose Start in this form. Choose Create a rule, or New rule if you already saved a rule in this form.
  2. Enter “Facilities requests” in Rule name. Under When, pick “What do you need?” Choose contains and select Room setup. Under Send to, choose This address and enter the facilities address. Write the subject and message. Choose Save, then Save rule.
  3. Choose New rule and enter “AV requests” in Rule name. Pick the same question. Choose is any of and select Microphone and Projector. Hold Ctrl on Windows or Command on Mac to select both in the list. Set This address to the AV address. Write the subject and message. Choose Save, then Save rule.

On a checkbox question, contains checks for a selected option. Use is any of when several options should match the same rule. Picking Microphone and Projector in a single response matches the AV rule once.

Check what each answer does

  • Leave the question blank. Neither rule matches.
  • Select Microphone or Projector. Only the AV rule matches, even if you select both.
  • Select Room setup and Microphone. With both rules running, expect one send attempt for the facilities rule and one for the AV rule. If you use the same address in both rules, you still get two send attempts.

Submit sample responses to a test form. Open each rule and use Preview to check the message with a sample. If you see Select a response, pick the one you want to check. Previewing doesn't send anything.

Turn on alerts. On Free, if you need to switch rules, choose Keep this rule on Free for the rule you want to test and confirm the switch. Then choose Send me a test. Check the sample and choose Send test to myself.

If you test your first rule before you add the second, you can use Preview and test when it appears. Check the sample and choose Turn on alerts and send test. Both test paths send the email to you.

To check the actual routes, use a fresh response on a test form with both rules running and addresses you control. Look in Send log, then check both inboxes. Sent means Google accepted the email for sending. Check the inbox to confirm it arrived.

When to use a different setup

If a response should go to only one team, make the question multiple choice instead. If you need one email with several recipients, CC or BCC, pick an add-on that supports those fields. An Answerfinch rule has one recipient address.
